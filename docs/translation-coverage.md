## 本次补充

- 设置说明、项目默认值、浏览器/通知设置和更新通道提示。

## 验证方法

运行 `npm run check`、`npm test`、`npm run pack:check`，并分别执行：

```sh
node tools/build-dict.mjs <对应版本的原始-server.asar> --untranslated <本地报告路径>
```

完整资源验证会重新解析已翻译的 JavaScript，并核对重建后所有非替换资源与原始字节一致。回归测试检查 TSV 与 JSON 同步、插值的数量和顺序、间接文案匹配，以及模型名、路由和协议状态值的保留。

## 覆盖边界

这不是逐屏交互验收，也不代表 100% 的英文都应替换。扫描器仍分别报告 925 / 926 个未收录的独立候选字符串，其中包含品牌名、命令、路径、CSS、协议标识、第三方库错误及工具协议说明，不能将此数字直接当作界面漏译数量。

终端输出、模型回答、仓库文件、用户内容和服务端返回的动态文案不会通过替换前端固定字符串自动翻译。仍需根据具体页面和上下文继续补充；无法确认用途的技术字符串保持原样。

本次资源验证仅覆盖上表两份 Windows 构建，不代表所有平台或相同版本号的其他构建已经完成验证。修改未自动应用到已安装的 T3 Code，也未发布到 npm。
